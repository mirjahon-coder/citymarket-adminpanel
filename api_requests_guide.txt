Mobil ilova uchun API request guide
==================================
Base URL: http://localhost:8000

Umumiy qoidalar
- Har bir so'rovda Content-Type: application/json
- Agar endpoint auth talab qilsa, Authorization: Bearer <token>
- Token olish uchun /api/auth/login yoki /api/auth/customer-login dan olinadi

1) AUTH

POST /api/auth/register
Body:
{
  "phone": "+998901234567",
  "password": "123456",
  "full_name": "Ali"
}

POST /api/auth/customer-login
Body:
{
  "phone": "+998901234567",
  "password": "123456"
}

POST /api/auth/verify-sms
Body:
{
  "phone": "+998901234567",
  "password": "123456"
}

POST /api/auth/login
Body:
{
  "username": "admin",
  "password": "123456"
}

GET /api/auth/me
Headers:
Authorization: Bearer <admin_token>

POST /api/auth/admins
Headers:
Authorization: Bearer <admin_token>
Body:
{
  "username": "newadmin",

}
